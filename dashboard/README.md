# Power BI Dashboard

The Power BI dashboard developed for this project contains three analytical pages:

1. **Executive Overview** — summarizes revenue, orders, customers, average order value, monthly revenue trends, top product categories, and geographic performance.

2. **Customer & Retention Analysis** — presents RFM customer segments, customer lifetime value (CLV) segments, revenue contribution, and retention patterns.

3. **Predictive Analytics** — presents repeat-purchase model performance, model comparisons, customer propensity scores, and actual repeat-purchase rates across propensity bands.
